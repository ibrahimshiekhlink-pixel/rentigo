04 — What's Never Included (Any Package)

Clear boundaries. No surprises.

This is a UI/UX design project. The following are outside this scope and will always require a separate engagement or a different provider.

⚙️
Backend / API Integration
No real data will flow through the prototype. All screens are static UI mockups. Your developer connects the real backend separately.
💻
Frontend Code Implementation
We deliver Figma design files and an interactive Vercel prototype. Writing production-quality React/Vue/Angular code is not included.
📱
Mobile App Design
This project covers the web admin panel only. Native iOS or Android app design is a separate project entirely.
🌙
Dark Mode Theme
Only the light/standard theme is designed. A dark mode variant can be added as a separate add-on for an additional fee.
🎞️
Animations & Motion Design
Basic hover states are included. Complex micro-animations, page transitions, and motion design are not in scope.
🔧
Post-Delivery Support
Once files are delivered and revisions completed, ongoing support is a separate arrangement billed at an agreed hourly rate.
🌐
Multi-Language / Localization
All designs will be in English only. Urdu, Arabic, or any other language version is not part of this scope.
🎨
Custom Illustrations / Photography
We use stock icons and standard UI elements. Custom hand-drawn illustrations or original photography are not included.

⚠️ Scope Creep Protection

Any request that falls outside the agreed package will be treated as a change request and quoted separately before work begins.

  • Additional screens beyond your package: 2,000 PKR per screen
  • New modules not in original scope: Quoted separately
  • Revisions beyond included rounds: 1,000 PKR per round
  • Rush delivery requests: 50% surcharge on remaining balance
05 — Revision Policy

Revisions are included. With clear rules.

Revision Rules — No Ambiguity

  • R1 2 revision rounds included in all packages. A "round" means one batch of consolidated feedback — not individual drip comments over multiple days. You collect all feedback, send it in one message, we implement it. That's one round.
  • R2 Feedback must be submitted within 5 business days of receiving a deliverable. After 5 days without response, the deliverable is considered approved and we move forward. Timelines will not shift due to delayed feedback.
  • R3 Revisions apply to the agreed screens only. Requesting a completely new screen, a new module, or a fundamentally different layout is not a revision — it's a new scope item and will be quoted separately.
  • R4 Revisions must be specific. Feedback like "make it better" or "it doesn't feel right" will require clarification before implementation. Vague feedback is not actionable and may consume your revision round.
  • R5 One point of contact for feedback. If multiple people are reviewing (team, stakeholders), feedback must be consolidated by you before sending. Conflicting feedback from different people in separate messages will not be accepted simultaneously.
  • R6 Additional revision rounds: 1,000 PKR each. Requested before the round begins. Paid before implementation starts. No exceptions.
